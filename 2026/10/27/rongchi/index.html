T2 扮演方案

简化题意

给定 nnn（1≤n≤501 \le n \le 501≤n≤50）个数，第 iii 个数为 wiw_iwi​（0≤wi≤220−10 \le w_i \le 2^{20}-10≤wi​≤220−1），将这些数分为两组，使得第一组的所有数按位与和第二组所有数按位与的值相等，求这种分组的方案数。

先转化条件，如果在所有数字中这一二进制位存在 0，那么每一组这一位中就必须有 0。

如果直接计算，要考虑 0 的分布，会比较麻烦，所以考虑容斥，通过总方案数减不合法方案数，这样只需要让 0 都在一边就可以了。

首先考虑全部方案，就是 2n2^n2n 减去空集的方案，即 2n−22^n-22n−2。

设 wi,jw_{i,j}wi,j​ 代表 wiw_iwi​ 二进制的第 jjj 位。

即钦定一个 SSS 集合，其中包含的元素 kkk 为在第 kkk 二进制位不合法，想让所有的 kkk 都违法，那对于每一个 wi,k=0w_{i,k}=0wi,k​=0 都要在一起。

枚举这个集合 SSS，朴素算法 O(2n2)=O(22n)O(2^{n^2}) = O(2^{2n})O(2n2)=O(22n) 还要带 505050 倍常数，会超时。

考虑使用并查集优化，这样集合之间可以转移，集合 SSS 可以从集合 S−lowbit⁡(S)S-\operatorname{lowbit}(S)S−lowbit(S)，其中 lowbit⁡(S)\operatorname{lowbit}(S)lowbit(S) 表示 SSS 从右往左第一位 1 的权值。

这样时间复杂度就降到 O(2n)O(2^n)O(2n) 带 505050 倍常数了。

T3 跳跃

简化题意

一个二维网格图，给出 mxmxmx、mymymy、nnn 和数列 badbadbad，每次一步操作，从一个点 （x,yx,yx,y） 到另一个点 （x1,y1x_1,y_1x1​,y1​），满足以下条件:

  • 0≤x1−x≤mx0 \le x_1-x \le mx0≤x1​−x≤mx，0≤y1−y≤mx0 \le y_1-y \le mx0≤y1​−y≤mx，点 (x,y)(x,y)(x,y) 与点 (x1,y1)(x_1,y_1)(x1​,y1​) 不是同一个点。
  • 对于 i=1i=1i=1 到 nnn，x1−x≠bix_1-x \ne b_ix1​−x=bi​ 并且 y1−y≠biy_1-y \ne b_iy1​−y=bi​。

现在给出 txtxtx、tytyty、rrr，求从点 (0,0)(0,0)(0,0) 到点 (tx,ty)(tx,ty)(tx,ty) 恰巧走 rrr 步的方案数，对 100071000710007 取模。

设 dpi,x,ydp_{i,x,y}dpi,x,y​ 表示走了 iii 步，到了点 (x,y)(x,y)(x,y) 的方案数，如果第一条条件中：点 (x,y)(x,y)(x,y) 与点 (x1,y1)(x_1,y_1)(x1​,y1​) 可以是同一个点，那么 dpdpdp 中的 x,yx,yx,y 便无互斥条件。设 dpxi,xdpx_{i,x}dpxi,x​ 表示走了 iii 步，到了第 xxx 行的方案数，dpyi,ydpy_{i,y}dpyi,y​ 表示走了 iii 步，到了第 yyy 列的方案数，则 dpi,x,y=dpxi,x×dpyi,ydp_{i,x,y}=dpx_{i,x} \times dpy_{i,y}dpi,x,y​=dpxi,x​×dpyi,y​，然后将 000 加入 badbadbad 数组，就等价于原本的问题。

那么可以分别处理 dpxdpxdpx 和 dpydpydpy，剩下的就是处理 badbadbad 的数组。

考虑容斥。（考虑容斥的原因：正难则反，这里的问题在独立处理单个条件时可能会涉及到其他条件，且不考虑其他条件是便于处理，其中有重复部分也可以用相似方法处理；本问题中只有一步非法很好处理，但是可能涉及其他违法步数，便有重复步数）

考虑问题本质，实际上无论在第几步非法，只要非法的次数和总非法路程不变，就不会改变答案（这是显然可得的）。

所以设 fi,kf_{i,k}fi,k​ 代表再 rrr 步中有 iii 步违法，其中的 badbadbad 和为 kkk 的方案数，fff 数组很好求，背包dp 即可。

当我们确立 fff 数组时，答案就很好求了，对于 fi,kf_{i,k}fi,k​，剩下 r−ir-ir−i 步，剩余网格的长宽分别为 tx−k,ty−ktx-k,ty-ktx−k,ty−k 自由走的方案数就是 dpr−i,tx−k,ty−kdp_{r-i,tx-k,ty-k}dpr−i,tx−k,ty−k​，同时，无需固定这 iii 步在 rrr 的位置，所以还要乘上 (ri)\dbinom{r}{i}(ir​)。

整合得:

dpr−i,tx−k,ty−k×fi,k×(ri)dp_{r-i,tx-k,ty-k} \times f_{i,k} \times \dbinom{r}{i}dpr−i,tx−k,ty−k​×fi,k​×(ir​)

在一次非法步数时，会重复计算两次非法的，计算两次时，又会重复计算三次的，以此类推。

这就是容斥，由上文得答案为下式:

∑i=0r∑k=0min⁡(tx,ty)(−1)i×dpr−i,tx−k,ty−k×fi,k×(ri)\sum^r_{i=0} \sum^{\min(tx,ty)}_{k=0} (-1)^i \times dp_{r-i,tx-k,ty-k} \times f_{i,k} \times \dbinom{r}{i}i=0∑r​k=0∑min(tx,ty)​(−1)i×dpr−i,tx−k,ty−k​×fi,k​×(ir​)
