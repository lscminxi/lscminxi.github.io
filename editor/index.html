写作说明与语法速查（点开查看）

实时预览仅在本地浏览器生成，不会保存或发布到服务器。内容写入后会自动保存到本地浏览器（localStorage），关闭或刷新页面后再次打开会恢复。点「下载 .md」可将内容保存为本地文件。

  • 公式：行内 $a_i^2$；独立公式用 $$ 单独成行。正文区按 Shift+↑ 可搜索并插入 LaTeX 符号。
  • 折叠框：:::info[标题] 或 :::success[标题]，用 ::: 结束。
  • 函数图与关系图：用 ```plot 或 ```graph 代码块编写，每行一条指令。

函数图 ```plot：画曲线、点与线段

```plot
title: 抛物线与直线
f: x^2 - 2x + 1 ; color=red ; width=3
f: -x + 3 ; color=green
points: (1, 0), (3, 2) ; connect=true ; color=blue ; size=5
line: (-2, 4), (4, -2) ; color=purple
x: -3, 5
y: -2, 10
grid: on
coords: on
intersections: on
interactive: on
```

关系图 ```graph：点、边、边权与算法

```graph
title: 带权示例图
directed: true
algo: reader
node: A ; label=起点 ; color=red ; weight=5 ; x=0 ; y=0
node: B ; 点权=3 ; x=120 ; y=0
edge: A -> B ; label=直达 ; weight=3 ; color=blue
edge: B -> C ; 边权=2
edge: C -- A ; weight: 5
edge: A -[4]- C
```

函数图和关系图右上角有「下载 PNG」，可把当前画面导出为图片。编辑器内容仅保存在本地，点「下载 .md」可将源码保存为文件。
