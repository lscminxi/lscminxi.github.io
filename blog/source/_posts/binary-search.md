二分查找的难点，往往不是「每次砍掉一半」，而是弄清楚：**答案可能在哪，哪些位置已经被排除了。**

本文用一个最基础的问题来说明：在非递减数组中，找到第一个大于或等于 `x` 的元素下标。

<!-- more -->

## 问题与约定

给定长度为 `n` 的非递减数组 `a`，下标从 `0` 开始。若不存在大于或等于 `x` 的元素，返回 `n`。

例如，`a = [1, 3, 3, 7, 9]`：

| x | 返回值 | 含义 |
| --- | --- | --- |
| 3 | 1 | 第一个 3 的下标 |
| 4 | 3 | 7 是第一个大于或等于 4 的元素 |
| 10 | 5 | 不存在符合条件的元素 |

## 维护不变量

使用左闭右开的待检查区间 `[l, r)`，初始时 `l = 0, r = n`。

在循环的任何一次开始时，都保持：

- `[0, l)` 中的元素全部小于 `x`。
- `[r, n)` 中的元素全部大于或等于 `x`。
- `[l, r)` 中的元素尚未确定。

取中点 `mid = l + (r - l) / 2`：

- 若 `a[mid] < x`，根据单调性，`mid` 以及它左边的元素都不是答案。因此令 `l = mid + 1`。
- 否则，`mid` 及其右边都满足条件，但还需要向左找第一个，因此令 `r = mid`。

当 `l == r` 时，待检查区间为空，`l` 正是所求的分界位置。

## C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// a 必须按非递减顺序排列。
// 这里假设数组长度能用 int 表示。
int first_ge(const vector<int>& a, int x) {
    int l = 0, r = static_cast<int>(a.size());
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < x) {
            l = mid + 1;
        } else {
            r = mid;
        }
    }
    return l;
}

int main() {
    vector<int> a = {1, 3, 3, 7, 9};
    cout << first_ge(a, 3) << '\n';   // 1
    cout << first_ge(a, 4) << '\n';   // 3
    cout << first_ge(a, 10) << '\n';  // 5
}
```

### 复杂度

每次循环都会把待检查区间缩小约一半。时间复杂度为 **O(log n)**，额外空间复杂度为 **O(1)**。空数组直接返回 `0`。

## 边界检查清单

- 空数组是否正常返回？
- 数组只有一个元素时，两种分支是否都能终止？
- 所有元素相等时，能否找到第一个？
- `x` 比最小值还小、比最大值还大时，返回值是否正确？
- 返回 `n` 时，调用方是否避免了访问 `a[n]`？

## 再往前一步

标准库中的 `std::lower_bound` 完成的是同样的查找任务。学习模板不是为了重复造轮子，而是为了理解它为什么正确。

二分答案则把「有序数组」推广为一个单调判定函数：先确定单调性，再写边界和循环不变量，最后才是代码。
