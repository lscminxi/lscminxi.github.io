## 新的开始

原来的页面来自 Hexo 默认模板。现在，博客有了自己的名字、主题，以及能够继续写作的 Markdown 源码。

## 怎样添加文章

在项目的 `blog/` 目录下运行：

```bash
npm run new -- "我的第一篇题解"
```

打开 `source/_posts/` 下生成的 Markdown 文件，就可以填写标题、分类、标签和正文了。

推荐使用英文短文件名，以便得到简洁的文章链接；文章标题仍然可以使用中文。

## 怎样预览

```bash
npm run dev
```

在本机浏览器打开 `http://localhost:4000`。部署说明、目录结构和常见操作见仓库的 `README.md`。
