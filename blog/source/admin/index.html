登录管理后台

这个站点是纯静态的 GitHub Pages，没有自己的服务器。后台使用 GitHub 令牌登录，浏览器直接调用 GitHub API 读写仓库文件： 新建文章、在线编辑、上传图片、实时删除，全部以你的身份提交到 main 分支，随后由 GitHub Actions 自动生成并发布静态页面。

怎么获取令牌？
  1. 打开 GitHub → Fine-grained tokens → Generate new token。
  2. Repository access 选 Only select repositories，选中 lscminxi/lscminxi.github.io。
  3. Permissions → Repository permissions → Contents 设为 Read and write（其余保持默认，不需要额外权限）。
  4. 生成后复制令牌，粘贴到上面的输入框登录。令牌只会发送到 api.github.com，不会经过任何第三方服务器。

也可以使用带 repo 权限的 classic token，但细粒度令牌更安全。随时可以在 GitHub 上撤销。
