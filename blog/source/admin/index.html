写作说明与语法速查（点开查看）

实时预览仅在本地浏览器生成，不会保存或发布。函数图与关系图都是「每行一条指令」：一行写错只会忽略那一行，不会让整篇文章发布失败；# 或 // 开头是注释，附加选项写在分号 ; 后面。

  • 公式：行内 $a_i^2$；独立公式用 $$ 单独成行。正文区按 Shift+↑ 可搜索并插入 LaTeX 符号（可搜 \pm、正负、积分、分数等中文叫法）。
  • 折叠框：:::info[标题] 或 :::success[标题]，用 ::: 结束。编辑区滚过折叠框、函数图或关系图源码时，预览会按块内进度缓慢下移对齐。

函数图 ```plot：画曲线、点与线段

```plot
title: 抛物线与直线
f: x^2 - 2x + 1 ; color=red ; width=3
f: -x + 3 ; color=green ; dash=true
points: (1, 0), (3, 2) ; connect=true ; color=blue ; size=5
line: (-2, 4), (4, -2) ; color=purple
x: -3, 5
y: -2, 10
grid: on
coords: on
intersections: on
interactive: on
```
  • f: 表达式 画一条函数曲线；也可以把表达式单独写一行。支持 + - * / ^、括号、隐式乘法（如 2x、2(x+1)）、常数 pi、e、tau，以及 sin cos tan asin acos atan sqrt abs exp ln log log10 floor ceil round。选项：color= 颜色、width=1~6 线宽、dash=true 虚线。
  • points: (x,y), ... 画散点；加 connect=true 依次连成折线，可配 color= 与 size=2~9。line: (x1,y1), (x2,y2), ... 是必然连线的简写。
  • x: 最小值, 最大值、y: 最小值, 最大值 固定坐标范围；不写 y: 时按曲线和点的范围自动留边距。title: 是图下方标题。
  • grid: on/off 控制网格；coords: on/off 控制选中点或交点后是否显示坐标；intersections: on/off 控制是否标出交点；interactive: off 生成静态图（仍可下载 PNG）。平时图中不写方程，选中曲线或线段时才显示方程式，选中点或交点时显示坐标。
  • 颜色可写英文或中文名（red、红色、blue、green、orange、purple、pink、teal、gray、black、yellow、brown）或 #RRGGBB。

关系图 ```graph：点、边、边权与算法

```graph
title: 带权示例图
directed: true
algo: reader
node: A ; label=起点 ; color=red ; weight=5 ; x=0 ; y=0
node: B ; 点权=3 ; x=120 ; y=0
node: C[2] ; x=60 ; y=100
edge: A -> B ; label=直达 ; weight=3 ; color=blue
edge: B -> C ; 边权=2
edge: C -- A ; weight: 5
edge: A -[4]- C
```
  • node: 点名 声明点；点名可用字母、数字、下划线、连字符或中文。选项有 label=显示文字、color= 颜色、size=10~34 半径、x= / y= 坐标（y 越大越靠下）。点权可写 node: A ; weight=5、点权=5、权重=5，或直接写 node: A[5]、node: A(5)；点权数字会显示在点的右上角小圆角标里，悬停或点击点时也会读出，可写小数或负数。边里出现但没声明的点会自动创建，位置自动布局；写了坐标就按坐标摆放。后台预览里点「调整点位」可拖动节点，最后点「保存点位」一次性写回坐标；也可以在调整模式下点选一个点，在图工具栏的「点权」框里填数字并点「设置点权」直接写回源码（「清除点权」会删掉它），不必手写语法。
  • edge: A -> B 是有向边（需同时写 directed: true 才画箭头），edge: A -- B 或 edge: A - B 是无向边；也可以把 A -> B 单独写一行。边选项有 label=名称、color= 颜色、dash=true 虚线。同一对点可写多条边，会自动画成弧线错开；edge: A -> A 是自环。
  • 边权（重点）：推荐写 edge: A -- B ; weight=5；也支持 w=5、边权=5、权重=5、weight: 5，或直接把数字写进边里：A -[5]- B、A --[5]-- B、A -[5]-> B，还可以用 label=5 把纯数字标注当边权。边权可写小数或负数，图上的权重数字会以更大的粗体显示；同时写名称和边权时会显示「名称 · 边权 5」。不写边权时算法按 1 计算，最小生成树会使用这些边权。
  • directed: true/false 决定 -> 是否按有向边处理；title: 是图下方标题。
  • algo: 决定图算法展示：reader（默认）让读者自选；components 连通分量、bridges 桥与割点、mst 最小生成树、bipartite 二分图、vbcc 点双连通分量、ebcc 边双连通分量、dfs DFS 树（返祖边）表示作者指定，打开页面就显示结果；none 不显示算法。也可写中文，如 算法：最小生成树。上方「插入可视化图」下拉可直接生成带算法设置的新图。
  • 函数图和关系图右上角都有「下载 PNG」，会把当前缩放/平移及算法高亮后的画面导成图片；编辑时也可以先在预览里调好再下载。
