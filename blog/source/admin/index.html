登录管理后台

后台只有站长 @lscminxi 能进入，有两种验证方式，任选其一：

方式一：GitHub 授权（推荐，不用自己保管令牌）

方式二：粘贴 GitHub 令牌

两种方式的验证标准完全相同：本站都会向 GitHub 确认令牌/授权对应的账号就是站长， 并且对仓库有写权限，其他账号一律显示「你无权限进入」。令牌需要能读写本仓库： 经典令牌勾选 repo，或细粒度令牌给本仓库 Contents 读写权限。 不勾「记住此设备」时，令牌只保存在当前标签页的会话里，关闭标签页或退出登录即失效； 勾选后会写进这台设备的 localStorage，请勿在公共电脑上勾选。
